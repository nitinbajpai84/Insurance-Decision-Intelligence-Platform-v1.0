# Demo Assets

This folder contains the client-demo support pack for the Insurance Intelligence Product.

## Files

- `3-minute-client-demo-script.md`: timed presenter script.
- `demo-click-path.md`: exact navigation path, validated questions, and safety notes.
- `final-3-minute-video-script.md`: final narration used for the walkthrough recording.
- `demo_readiness_report.md`: generated by `scripts/demo_readiness_check.py`.
- `demo_readiness_results.json`: generated machine-readable readiness results.
- `screenshots/`: generated screenshots from the walkthrough script.
- `videos/`: generated WebM video recording.

## Run Order

From the repository root:

```powershell
cd C:\Users\Nitin\Documents\Codex\2026-05-29\act-as-an-enterprise-insurance-data
.\.venv\Scripts\Activate.ps1
python scripts\demo_readiness_check.py
node scripts\record_three_min_demo_video.mjs
```

If the backend is not running:

```powershell
python -m uvicorn copilot_api_gateway.api:app --host 127.0.0.1 --port 8071
```

If the frontend is not running:

```powershell
cd frontend
npm.cmd run dev
```

The local frontend uses `NEXT_PUBLIC_DEMO_MODE=true` in `frontend/.env.local`.
